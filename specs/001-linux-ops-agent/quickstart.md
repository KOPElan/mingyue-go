# Quickstart: Linux 系统操作代理（开发者）

> 本文用于开发与验证（计划阶段），具体命令与参数以实现落地后为准。

## 1. 前置条件

- Go 1.25.7+
- Linux 测试环境（推荐）
- 部分功能需要 root 或 capabilities（例如挂载/卸载、共享管理），遵循最小权限原则

## 2. 本地构建

- 整理依赖：`go mod tidy`
- 构建：`go build ./...`
- 测试：`go test ./...`

## 3. CLI 直接运行（预期形态）

- 查看帮助：`./mingyue --help`
- 输出 JSON：命令统一支持 `--json`

## 4. 守护进程运行（预期形态）

- 启动守护进程：`./mingyued`
- 健康检查：`GET /api/v1/health`

## 5. OpenAPI/Swagger 交付物

- OpenAPI 源文件位置：`specs/001-linux-ops-agent/contracts/openapi-v1.yaml`
- 目标：实现阶段在 CI 或本地提供校验/生成机制，避免文档与实现漂移。

## 6. 最小权限验证（预期形态）

- 只读接口：在非特权模式下可正常工作
- 变更接口：在权限不足时必须返回一致错误码与可解释错误信息

## 7. 审计验证（预期形态）

- 任何变更类操作（kill、挂载/卸载、共享变更、文件写）都必须生成审计事件
- 审计事件不包含敏感信息（如远端挂载凭据）
